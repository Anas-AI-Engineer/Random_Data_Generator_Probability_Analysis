# 🎲 Random Data Generator & Probability Analysis

A Python project that generates random data and performs probability analysis using NumPy. It focuses on random number generation, probability calculations, and basic statistical concepts.

## ✨ Features

- Generate random numbers using Python and NumPy.
- Perform probability calculations.
- Analyze generated data.
- Calculate basic statistical measures.
- Practice probability and statistical analysis.

## 🛠️ Technologies Used

- Python
- NumPy

## 🚀 Getting Started

### Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Install Dependencies

```bash
pip install numpy
```

### Run the Project

```bash
python main.py
```

*Replace `main.py` with your actual Python filename if needed.*
